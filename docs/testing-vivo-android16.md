# vivo V2458A / Android 16：第一轮测试

目标是确认诊断版可以在手机启动、识别已安装原版并导出足够的技术信息。本轮不验证汉化效果，不要求 Root、Shizuku、电脑或修改游戏文件。

## 安装

1. 将 `LCBLauncher-0.1.0-probe-debug.apk` 复制到手机并安装；按系统提示允许本次安装来源。
2. 打开应用「边狱启程」。安装包名为 `io.github.lcblauncher`，不会覆盖游戏原版。
3. 首页应显示当前游戏版本、安装包数量、手机型号、Android 版本、内存页大小和可用空间。

不要卸载原版或清除游戏数据。第一版启动器也不提供这些操作。

## 启动与诊断

1. 在首页确认游戏已检测到，点击「启动原版游戏」，在提示中选择「打开原版」。
2. 观察是否打开游戏并能进入平常的登录或主界面。当前应该仍是原文，没有汉化属于预期。
3. 从最近任务返回「边狱启程」，进入「诊断」。
4. 在「原版启动结果」选中实际结果。启动器不会自行推断游戏是否登录成功。
5. 点击「导出诊断 JSON」，在系统文件选择器里保存文件。
6. 将这个 JSON 发回，并说明安装是否成功、页面是否显示正常、原版是否启动成功。若有明显界面问题，可以附上相关页面截图。

如果系统没有检测到原版，先确认游戏与启动器装在同一个用户空间；导出诊断后反馈，不需要移动或重装游戏。

## 可选：汉化包检查

只有你手头已有 ZIP 格式汉化包时才需要测试：

1. 进入「汉化包」，选择含 JSON 文本的 ZIP 文件。
2. 成功后应显示 JSON 文件数、显示字段数量、大小与 SHA-256，状态应明确为「尚未应用」。
3. 退出并重新打开启动器，检查包信息是否仍存在。

目前不支持 7z，ZIP 结构通过也不意味着与游戏版本匹配。此功能不会修改游戏数据。

## 诊断内容

设备型号、系统版本、ABI、页大小、存储和内存、指定 Google 组件是否安装、游戏版本／安装来源／签名摘要／安装包结构，以及手动测试结果。

不包含账号、存档、设备唯一标识、游戏 APK、汉化正文或文档 URI。没有自动上传功能，诊断由你选择位置保存后发送。
